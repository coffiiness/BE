== Overview

Coffiiness Core API 명세서입니다.

[cols="1,3"]
|===
|Base URL |`https://api.calfit.com`
|Content-Type |`application/json`
|인증 방식 |JWT Bearer Token
|멀티테넌시 |`X-Tenant-ID` 헤더로 워크스페이스 식별
|===

TIP: 인증이 필요한 API는 `Authorization: Bearer {token}` 헤더를 포함해야 합니다.
